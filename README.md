# Innovación Docente

Proyecto de ejemplo desarrollado con Vue 3, Vite y TypeScript para mostrar prácticas, convocatorias y proyectos de innovación docente.

## Vista rápida
- **Stack:** Vue 3, Vite, TypeScript, Pinia, Vuetify.
- **Requisitos:** Node.js 20.19+ o Node >=22.12.0, npm.

## Instalación
Ejecuta en la carpeta del proyecto `innovacion-docente`:

```bash
npm install
```

## Comandos útiles
```bash
npm run dev       # Inicia servidor de desarrollo (vite)
npm run build     # Construye la app
npm run preview   # Previsualiza la build
npm run type-check # Comprueba tipos con vue-tsc
npm run lint      # Ejecuta linters
npm run format    # Formatea el código con Prettier
```
